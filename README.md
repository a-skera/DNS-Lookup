# DNS-Lookup
A command-line utility for retrieving and analyzing DNS records associated with a domain.



## Features

- A record lookup
- AAAA record lookup
- MX record lookup
- NS record lookup
- CNAME record lookup
- TXT record lookup
- DNS error handling

## Installation

pip install -r requirements.txt

## Usage

python dns_lookup.py google.com

## Technologies

- Python
- dnspython
- argparse

Educational networking and cybersecurity
reconnaissance utility.
